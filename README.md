# 춘식이 데스크톱 펫

Windows 작업표시줄 위의 캐릭터, 알림, 포스트잇, 타이머·스톱워치 프로그램입니다.
만든이: **kkongt2.kang** · 현재 버전: [VERSION](VERSION)

## Chromium / WebView2 입력 위치 피하기

기존 Win32 커서 감지가 실패하면 UI Automation으로 포커스된 편집 가능한 입력 요소의 커서·인접 문자·현재 줄 좌표를 확인합니다. 정확한 좌표가 없으면 작은 입력창 영역까지만 사용하며, 문서 전체나 큰 편집기 영역은 회피하지 않습니다. 입력 텍스트나 비밀번호는 읽지 않습니다.

UIA 조회는 단일 백그라운드 MTA 스레드에서 처리하고 오래된 결과는 폐기합니다. 앱이 응답하지 않으면 추가 조회를 쌓지 않으며 기존 Win32·마우스 회피는 계속 동작합니다. 설정 → 프로그램 → 진단 정보에서 최근 감지 방식/조회 상태를 확인할 수 있습니다. WebView2 호스트의 접근성 지원에 따라 감지되지 않을 수 있습니다.

## 초대형 춘식이

- 춘식이 우클릭 → **크기 → 초대형 춘식이 (화면 가득)**. 트레이의 모든 춘식이 설정에서도 선택할 수 있습니다.
- 현재 모니터의 작업표시줄을 제외한 높이에 맞춥니다. 좁은 세로 모니터에서는 그림 비율을 유지하면서 가로 폭 안에 맞춥니다.
- 제자리에 고정되어 걷거나 피하지 않으며, 드래그 이동·비행도 하지 않습니다. 모니터 이동 메뉴는 사용할 수 있고 도착한 화면에 다시 맞춥니다.
- 일반 춘식이와 동일하게 클릭하면 간지럼 반응을 보이고, 연속 클릭하면 웃습니다. 전용 클릭 멘트는 없습니다. 우클릭의 **보통 크기로 돌아가기**로 즉시 줄일 수 있습니다.
- 초대형 선택 상태도 저장되어 재실행 시 복원됩니다.

## 춘식이 목록 · 모니터 관리 (1.51.0)

- **설정 → 캐릭터** 상단에서 각 춘식이의 모니터, 크기, 걷기/쉬기, 속도를 확인합니다. 목록 선택 또는 **위치 확인**으로 해당 춘식이에 1.8초 동안 파란 테두리를 표시합니다. 방해 금지 중에는 강조도 숨겨집니다.
- 목록에서 선택한 춘식이의 걷기/쉬기와 속도를 변경할 수 있습니다. 개별/전체 속도는 즉시 자동 저장되며 재실행 후에도 복원됩니다. 이전 설정은 보통 속도로 시작합니다.
- 모니터를 선택하고 **선택 춘식이 이동** 또는 **선택 모니터로 모두 모으기**를 누릅니다. **설정 창이 있는 모니터로 모두 모으기**도 제공합니다. 크기·속도·걷기/쉬기 모드는 유지하고, 이동 중인 비행/드래그는 끝냅니다.
- 춘식이 우클릭에도 모니터 이동/현재 춘식이의 모니터로 모으기가 있고, 트레이에는 **마우스가 있는 모니터로 모두 모으기**가 있습니다. 여러 마리는 화면 가로 방향으로 나누어 배치하며, 크기와 수에 따라 겹칠 수 있습니다.
- 위치는 화면 픽셀 좌표와 모니터 장치명·화면 내 상대 위치를 함께 저장합니다. 해상도·배율·배치가 바뀌면 연결된 같은 장치명의 모니터를 우선하고, 없으면 주 화면으로 복원합니다. Windows가 장치명을 재할당한 경우 같은 물리 모니터임을 보장하지는 않습니다.

## Visual Studio에서 EXE 빌드

1. **Visual Studio 2022**를 설치하거나 Visual Studio Installer에서 **수정**을 선택합니다. Visual Studio 2019에서도 열 수 있는 .NET Framework 프로젝트입니다.
2. 워크로드 **.NET 데스크톱 개발**을 선택합니다. 개별 구성 요소에서 **.NET Framework 4.8 SDK / Targeting Pack**도 설치합니다. 런타임만으로는 빌드할 수 없습니다.
3. 저장소를 Clone하거나 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
4. 루트의 **ChunsikPet.sln**을 Visual Studio로 엽니다.
5. 상단 구성을 **Release**, 플랫폼을 **x64**로 선택합니다.
6. **빌드 → 솔루션 빌드** (`Ctrl+Shift+B`)를 누릅니다.
7. 생성 파일: **ChunsikDesktopPet\bin\x64\Release\ChunsikPet.exe**

실행 테스트는 `F5`(디버깅) 또는 `Ctrl+F5`(디버깅 없이 실행)로 할 수 있습니다. 기존 춘식이가 실행 중이면 트레이 메뉴에서 먼저 종료하세요.
이미지와 휴일 CSV는 EXE에 포함됩니다. 배포할 때는 EXE 하나만 복사하면 됩니다. 대상 PC에는 .NET Framework 4.8 런타임이 필요합니다. PDB는 디버깅용이며 배포에 필수는 아닙니다.

### 명령줄 빌드

Visual Studio의 **Developer Command Prompt**에서 저장소 루트로 이동합니다.

```bat
msbuild ChunsikPet.sln /t:Rebuild /p:Configuration=Release /p:Platform=x64 /m
```

외부 NuGet 패키지를 사용하지 않으므로 개발 도구가 설치되어 있으면 오프라인으로 빌드할 수 있습니다.

### 빌드 오류 해결

- `MSB3644` 또는 .NET Framework 참조 어셈블리 없음: **4.8 Developer Pack** 설치 후 Visual Studio를 다시 엽니다.
- WPF 관련 참조 없음: .NET 데스크톱 개발 워크로드와 4.8 SDK/Targeting Pack 설치를 확인하세요.
- 출력 EXE를 덮어쓸 수 없음: 실행 중인 춘식이를 종료하세요.

[Microsoft 개발자 팩 안내](https://learn.microsoft.com/dotnet/framework/install/guide-for-developers)

## 실행 구조와 저장 위치

- 사전 컴파일된 C# / WPF / .NET Framework 4.8, Windows x64 프로그램입니다.
- PowerShell 실행, 실행 시 소스 컴파일, 난독화·패커는 사용하지 않습니다.
- 내장 PNG와 휴일 CSV만 `%LOCALAPPDATA%\ChunsikDesktopPet\assets-v32`에 준비합니다.
- 사용자 알림·할 일·캐릭터 설정은 `%LOCALAPPDATA%\ChunsikDesktopPet`에 저장합니다. 업데이트 후에도 기존 설정을 읽습니다.
- 공휴일 정보는 오프라인 CSV를 사용합니다. 임시공휴일 및 향후 법령 변경은 별도 데이터 갱신이 필요합니다.
- 빌드된 파일에는 디지털 서명이 없습니다. 직접 빌드해도 회사 보안 정책의 승인을 대체하지 않습니다. 차단될 때는 보안 담당자의 검토가 필요합니다.

## 추가된 사용자 기능 (1.33~1.39)

- 알림 행의 **▶ 보기**, 포스트잇의 **표시 미리보기**: 실제 발송 없이 모션·색상·문구를 확인합니다.
- 트레이의 **알림 이력 · 놓친 알림**: 최근 300건, 확인/다시 알림 상태, 다시 보기를 제공합니다. 절전 복귀 시 최신 누락 알림을 알림별 하나씩 복구합니다(최대 7일).
- **방해 금지**: 30분·1시간·직접 해제, 전체 화면 자동 숨김. 대기 알림은 해제 후 이어서 표시합니다.
- **설정 백업**: 단일 `.chunsik` 파일. 설정 창은 검증·저장 후 닫히며, 복원 후 EXE를 다시 실행해야 합니다. 복원 전 설정은 사용자 데이터 폴더에 보관됩니다. 알림 이력과 실행 중인 타이머는 백업 대상이 아닙니다.
- 포스트잇 완료 후 **12초 되돌리기**와 완료 날짜 표시.
- 캐릭터·알림·포스트잇·시간 도구·프로그램의 **통합 설정 탭**.
- 간격 알림의 **활동 시간 · 자리 비움**: 기본 제한 없음, 원하는 시간대만 동작하거나 입력 5분 이상 없으면 중단. 활동 복귀 후 간격을 새로 계산합니다. 자정을 넘긴 시간대도 현재 날짜의 요일 선택이 적용됩니다.
- 모니터·DPI 변경에 따른 창 위치 복구, 작은 화면의 알림 설정 가로 스크롤.

버전은 `VERSION`, 실행 파일 속성, 프로그램 정보, [CHANGELOG.md](CHANGELOG.md)에 기록합니다. 새 기능은 마이너 버전, 호환성을 유지하는 수정은 패치 버전을 올립니다.

GitHub Actions에서 Windows Release 빌드와 스케줄 테스트를 실행하고, 성공한 실행의 **Artifacts → ChunsikPet-Windows-x64**에서 EXE를 받을 수 있습니다.

### GitHub Release 자동·수동 게시

본문에는 이전 공개 Release 이후의 변경 요약, 포함된 전체 커밋과 링크, 전체 비교 링크를 담습니다. 첫 Release에는 해당 커밋까지의 전체 이력을 표시합니다.

`.github/`, `docs/`, `tests/`, README, CHANGELOG, VERSION, LICENSE, Git 설정 파일 변경은 게시 사유에서 제외합니다. `Program.cs`의 AssemblyVersion/AssemblyFileVersion 숫자만 바뀐 경우도 제외합니다. 이미지·휴일 CSV·소스·프로젝트 파일 등의 변경은 게시 대상입니다. push마다 가벼운 확인 작업은 실행되지만 문서·워크플로만 변경됐다면 Windows 빌드·새 태그·새 Release는 모두 건너뜁니다.

1. **main에 push하면 자동 실행**됩니다. **Actions → Publish latest Windows EXE → Run workflow**에서 **main**을 선택해 수동으로 실행할 수도 있습니다.
2. 실행 시점의 `main` 최신 커밋과 `VERSION`을 읽습니다. 최신 공개 Release 태그의 커밋부터 비교하여 실제 프로그램·리소스·빌드 입력이 변경됐을 때만 Windows 빌드 및 게시 작업을 실행합니다. EXE 빌드와 스케줄 테스트가 통과하면 `v버전` 태그, Release 게시글, 첨부 파일 **ChunsikPet.exe**를 만들고 Latest로 지정합니다.
3. 같은 태그의 Release가 이미 있으면 초안을 포함해 빌드·게시를 건너뜁니다. 기존 태그는 덮어쓰지 않으며, 태그만 존재하고 다른 커밋을 가리키면 오류로 중단합니다.

별도 토큰 설정 없이 워크플로의 `GITHUB_TOKEN`을 사용합니다. 게시 중 업로드에 실패하면 Release는 초안으로 남습니다. 재시도하려면 실패한 초안을 삭제한 후 다시 실행하세요. 기존 공개 Release의 본문은 같은 변경 내역 정책으로 갱신하며 태그·EXE는 변경하지 않습니다. 새 버전은 루트 `VERSION`만 변경합니다. MSBuild가 실행 파일의 AssemblyVersion·FileVersion·ProductVersion을 자동 생성하며 릴리즈도 같은 값을 사용합니다.

검증 범위와 수동 절차: [tests/WINDOWS-CHECKLIST.md](tests/WINDOWS-CHECKLIST.md). 물리 화면·절전·보안 제품 판정은 자동 테스트로 보장하지 않습니다.

## 포스트잇 직접 조작 (1.42.0)

- 할 일 앞의 자동 네모 표시를 제거했습니다. 각 포스트잇의 **A− / A+**로 글자 크기를 10~64 사이에서 조절할 수 있습니다.
- 상단의 **＋ 새 포스트잇**을 누르면 근처에 새 빈 포스트잇을 만들고 바로 입력할 수 있습니다. 빈 포스트잇도 재시작 후 유지됩니다(최대 50개).
- 우측 하단 **◢** 손잡이를 끌어 개별 창의 가로·세로 크기를 조절합니다. 크기와 글자 크기는 각각 저장됩니다.
- 내용을 **더블클릭**하거나 **편집**을 눌러 그 자리에서 수정합니다. Enter는 줄바꿈, **Ctrl+Enter**는 저장, **Esc**는 취소입니다. 다른 곳을 클릭해도 저장됩니다.
- 포스트잇의 우클릭 **포스트잇 설정**에서 표시 방식·색상 등 기존 옵션을 변경합니다. 편집 중인 메모는 주기 표시 시간이 지나도 숨기지 않습니다.

## 실시간 알림 카운트다운 (1.41.0)

알림 설정에서는 PC의 현재 시간과 각 알림의 다음 예정까지 남은 시·분·초가 1초마다 갱신됩니다(1.41.0). 알림 이름 아래에서 확인하고 마우스를 올리면 정확한 예정 날짜·시간을 확인할 수 있습니다. 간격 알림은 실제 실행 중인 마감 시각을 사용하며, 시간 미지정 날짜 알림은 ‘당일 프로그램 시작 시’로 표시합니다. 꺼짐·반복 요일 미선택·활동 시간 밖·자리 비움·방해 금지·순차 표시 대기도 구분합니다.

같은 날 이미 울린 알림의 시각을 바꾸면 새 시각에 다시 울릴 수 있습니다. 제목·문구만 바꾸면 기존 발송 기록은 유지합니다. 다음 알림이 기다리고 있으면 현재 알림의 마지막 문구도 설정된 문구 표시 시간이 지난 뒤 자동으로 넘어갑니다.

## 앉은 자세 마우스 회피 (1.40.0)

마우스 피하기 ON 상태에서 ‘모두 잠깐 쉬기’ 또는 캐릭터의 ‘잠깐 쉬기’를 켜도 커서를 피합니다. 자동으로 앉아 쉬던 캐릭터에도 적용됩니다. 상체를 세운 앉은 자세와 바닥 접촉 높이를 유지하고 양쪽 발만 움직이며 천천히 이동합니다. 커서가 멀어지거나 마우스 피하기를 끄면 이동을 멈추며, 수동 쉬기는 해제하지 않습니다. 알림 모션·드래그·수면 중 회피 제외 규칙은 유지합니다.

### 포스트잇 스마트 고스트 모드

- 평소에는 항상 위에 반투명하게 표시되며, 메모 본문·춘식이 영역의 클릭은 뒤쪽 프로그램으로 통과합니다. 기본 불투명도 60%(투명도 40%)이며 설정에서 10~100%로 조절합니다.
- 상단의 **수정/이동** 헤더를 누르면 불투명한 편집 모드로 바뀌고, 끌면 메모 위치를 옮깁니다. **＋ / ◐− / ◐+ / A− / A+ / ✓** 버튼과 크기 조절 손잡이는 고스트 모드에서도 바로 사용할 수 있습니다. 버튼에 마우스를 올리면 해당 버튼만 선명해집니다. 글자 크기 숫자는 표시하지 않습니다.
- 저장/취소, Ctrl+Enter/Esc 또는 다른 창 클릭으로 편집을 마치면 다시 고스트 모드가 됩니다. 저장 실패 시에는 편집 모드를 유지합니다.
- 편집 중 제목/춘식이를 끌어 이동하고 오른쪽 아래 손잡이로 크기를 조절할 수 있습니다. 우클릭 메뉴에서 할 일 완료도 가능합니다.
- 커서 회피, 회피 ON/OFF 버튼, Shift 안내는 사용하지 않습니다.

- 춘식이 얼굴과 팔은 헤더보다 앞쪽 레이어에 표시되며 클릭은 통과합니다.

- 헤더는 왼쪽 정렬하고 춘식이가 차지한 공간을 피해서 너비를 조절합니다. 하단 하늘색 ◐−/◐+ 버튼은 불투명도를 10%씩 낮추거나 높이며(10~100%), 글자 크기 버튼과 간격·색상으로 구분됩니다.

- 상단 **고스트 ON/OFF** 버튼으로 본문 클릭 통과를 켜거나 끕니다. OFF 상태에서는 본문도 일반 메모처럼 조작합니다. **−** 버튼은 메모를 작은 **▣ 메모** 탭으로 최소화하며 탭을 누르면 복원합니다. 모드와 최소화 상태는 메모별로 저장됩니다.

## 포스트잇 전체 숨김 / 보이기 (1.45.0)

- **Ctrl + Alt + Shift + Z**를 누르면 모든 포스트잇과 최소화된 `▣ 메모` 탭을 숨기고, 다시 누르면 복원합니다. 다른 프로그램을 사용 중일 때도 동작합니다.
- 위치·크기·최소화 상태를 유지합니다. 숨긴 동안 가끔 알림의 표시/대기 시간은 일시 정지하며, 새 메모도 다시 보이기 전까지 숨깁니다.
- 편집 중인 내용은 먼저 저장하며 저장 실패 시 숨기지 않습니다. 길게 눌러도 자동 반복 전환하지 않습니다.
- 트레이 메뉴 또는 포스트잇 설정의 **전체 숨김 / 보이기**로도 전환할 수 있습니다. 다른 프로그램이 단축키를 선점하면 등록 실패를 알리고 트레이 메뉴를 사용할 수 있습니다.
- 전체 숨김 상태는 실행 중에만 유지하며 재실행하면 정상 표시합니다. 개별 메모의 최소화 상태는 기존처럼 저장됩니다.

## 쉬기 모드 머리띠 (1.45.1)

직접 **잠깐 쉬기 / 모두 잠깐 쉬기**를 켜둔 춘식이는 앉은 자세에서 흰색 머리띠와 옆 매듭을 두릅니다. 자동 휴식에는 표시하지 않습니다. 앉아서 마우스를 피할 때도 유지하고 **다시 걷기**를 선택하면 즉시 벗습니다. 알림·간질·낙하산·수면 모션 중에는 해당 모션을 보여주며, 쉬는 자세로 돌아오면 다시 착용합니다.

## 마우스 + 키입력 피하기 (1.46.0)

- 기존 마우스 피하기 ON/OFF 설정을 그대로 이어받으며, 일반 춘식이가 마우스 및 최근 활동 중인 외부 앱의 입력 커서 주변에서 비켜납니다. 앉은 쉬기 모드에서도 동일하게 적용됩니다.
- 키를 구분하거나 글자를 읽지 않습니다. 기존 마지막 입력 시각 정보와 Windows가 제공하는 입력 커서 위치만 이용합니다. 키보드 후킹, 키 상태 조회, 텍스트 수집, 화면 캡처, UI Automation 탐색, 관리자 권한은 사용하지 않습니다. 조회한 위치는 메모리에만 잠시 유지하고 기록·전송하지 않습니다.
- 전체 춘식이가 위치 조회 결과를 공유하며 최대 초당 4회 조회합니다. 추가 스레드나 타이머를 만들지 않고, 모드 OFF·방해 금지·입력 활동 중단 시 위치 조회를 중단합니다.
- 키보드와 마우스 입력을 구분하지 않으므로 입력 칸에 포커스를 둔 채 마우스를 움직여도 입력 위치를 보호할 수 있습니다. 최근 입력 활동이 3초 이상 없으면 보호를 해제합니다(기존 0.5초 활동 조회 주기에 따른 오차가 있습니다).
- 표준 입력 커서를 제공하지 않는 앱/브라우저 편집기 및 권한 때문에 위치를 조회할 수 없는 앱에서는 마우스 회피만 적용합니다. 드래그·클릭 반응·알림 등 기존 회피 제외 동작을 유지합니다. 이동할 공간이 부족하면 가장 덜 겹치는 화면 가장자리로 이동합니다.
- 백신/회사 보안 제품의 판정은 해당 제품 정책에 따르므로 오탐이 없다고 보장할 수는 없습니다.

## 랜덤 낙하산 / 천사 날개 (1.47.0)

- 춘식이를 끌어 위에서 놓을 때마다 낙하산과 천사 날개 중 하나를 각각 50% 확률로 선택합니다.
- 낙하산은 기존 펼침·하강 속도·착지 접힘을 유지하고, 놓은 수직선에서 내려옵니다(화면 경계에서는 위치 보정).
- 천사 날개는 춘식이 등 뒤에서 움직이며 아래로 내려오는 동안 좌우로 낙엽처럼 부드럽게 이동합니다. 한 방향 이동은 약 2.2~3.8초이고 거리와 시간을 매번 새로 정합니다. 화면 경계를 넘지 않습니다.
- 착지하면 날개를 접고, 도중에 다시 잡거나 모니터 구성이 변경되면 낙하 효과를 정리합니다. 기존 낙하 타이머를 사용하며 추가 스레드/타이머는 없습니다.

## 기본 저녁 알림 (1.48.0)

저녁시간 알림이 기본으로 추가됩니다(평일 19:00, ON). 점심과 같은 식사 모션을 사용하며 알림 설정에서 ON/OFF·시간·요일·메시지를 변경할 수 있습니다. 기존 설정에는 누락된 저녁 알림만 추가하고, 이후 저장된 OFF 상태와 사용자 설정은 유지합니다. 기본 알림이므로 삭제 대신 OFF로 끌 수 있습니다.

## 빠른 설정 메뉴 (1.49.0)

일반 춘식이를 우클릭하면 상단의 세 버튼으로 해당 춘식이의 걷기/쉬기, 전체 춘식이의 입력 피하기 ON/OFF, 포스트잇 전체 숨김/보이기를 전환합니다. 현재 상태와 적용 범위를 표시하고 버튼을 눌러도 메뉴를 유지해 연속 조작할 수 있습니다. 기존 쉬기 메뉴는 빠른 버튼으로 통합했습니다.

## 짧은 상황별 반응 (1.50.0)

입력 회피를 마치면 잠깐 돌아보고(연속 반응은 4초 간격 제한), 수동 쉬기는 머리띠를 매고 앉는 동작, 다시 걷기는 기지개 후 출발 동작을 보여줍니다. 빠른 설정의 걷기/쉬기 버튼을 누르면 메뉴가 열린 상태에서도 전환 동작이 즉시 진행됩니다. 가까운 마우스로 인한 회피는 전환 동작이 끝난 뒤 이어집니다. 드래그·알림·수면·새 회피가 우선하며, 기존 타이머로 처리합니다.

비행 중 잡을 때는 날개/낙하산 해제 전에 클릭한 신체 위치를 화면 좌표로 기억하고, 창 크기 변경 후 같은 위치를 마우스 아래에 맞춥니다. 드래그 시작 시에도 위치가 다시 바뀌지 않습니다(1.50.2).


## 타이머·포스트잇 편의 기능 (1.52.0)

- 타이머 시작 전 **5/10/25/50분**, 시작 후에도 **+1분/+5분**을 사용할 수 있습니다. 측정 중 프리셋 변경은 막습니다.
- 실행 또는 일시정지한 시간 도구의 **×는 창만 숨김**입니다. 트레이에서 다시 열 수 있고, **측정 종료** 버튼은 측정을 끝냅니다. 숨긴 타이머 완료 시 다시 나타나며 방해 금지 중이면 해제 후 나타납니다. 앱 종료/재실행 시 측정은 유지되지 않습니다.
- 방해 금지 중 춘식이 애니메이션을 멈추며, 숨김/대기 상태 갱신은 1초 간격으로 줄입니다. 타이머 실제 경과 시간은 계속 측정합니다. CPU 절감률은 환경에 따라 다릅니다.
- **설정 → 포스트잇 → 단축키**에서 Ctrl/Alt(하나 이상), Shift와 문자·숫자·F1~F11을 선택하고 **충돌 확인 · 적용**을 누릅니다. 실패하면 기존 키를 유지합니다. 단축키는 별도 hotkey.txt에 저장하며 설정 백업 파일에는 포함되지 않습니다.
- 포스트잇 관리 화면에서 내용 검색과 **전체/미완료/완료 · 최근순** 필터를 사용합니다. 완료 기록의 **↶ 복원**으로 다시 표시할 수 있습니다. 기존 최대 50개 제한은 유지됩니다.

## 우클릭 메뉴 (1.53.0)

- 춘식이 우클릭: 빠른 설정, 개별 크기/속도, 모니터 이동, 이 화면으로 모으기, 한 마리 추가, 춘식이 관리, 개별 제거. 마지막 한 마리는 프로그램 종료 여부를 확인합니다.
- 트레이 우클릭: 타이머/스톱워치 상태, 포스트잇 숨김/관리, 모니터 선택 후 모으기, 모두 쉬기, 모든 춘식이 설정, 방해 금지, 알림 이력, 설정, 프로그램 종료.
- 테스트 알림은 설정 → 알림, 백업/복원·프로그램 정보는 설정 → 프로그램에 있습니다.
- 크기와 속도의 현재 선택을 체크하며 전체 설정값이 다르면 각각 다름을 표시합니다. 선명도는 100%가 완전히 선명함이며 기존 저장값은 그대로 호환합니다.

## 오류 진단 및 버전 (1.54.0)

- **설정 → 프로그램 → 오류 진단 정보 보기 · 복사**에서 버전, OS/CLR, 모니터 좌표·작업 영역·DPI, 단축키 등록 상태와 최근 오류를 확인하고 복사합니다. 시작/실행 오류 창에서도 진단 정보를 열 수 있습니다.
- 최근 오류 한 건은 `%LOCALAPPDATA%\ChunsikDesktopPet\last-error.txt`에 제한된 길이로 보관합니다. 사용자 프로필/앱 폴더 경로는 치환하고 메모·알림 본문은 별도로 수집하지 않습니다. 오류 메시지 자체에 포함된 내용은 공유 전 확인해 주세요. 자동 전송은 하지 않습니다.
- 버전 변경은 루트 `VERSION` 하나만 수정합니다(예: `1.54.0`). 빌드 시 `obj` 아래 버전 특성을 생성합니다. Visual Studio/MSBuild와 GitHub Actions 모두 동일하며 별도 Node/Python 도구가 필요 없습니다.
- `VERSION`이 없거나 형식/범위가 잘못되면 빌드에 실패합니다. 문서·버전만 변경한 경우 새 릴리즈를 생략하는 기존 정책은 유지합니다.
