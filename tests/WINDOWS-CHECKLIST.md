# Windows 수동 검증

자동 테스트는 스케줄 경계 21건을 확인하며 WPF UI·물리 모니터·절전은 아래 절차로 별도 검증합니다.

1. **미리보기**: 알림 모션, 메시지 여러 개의 자동 전환, 색상 변경을 확인합니다. 미리보기 이후 실제 알림 LastFired와 이력이 바뀌지 않는지 확인합니다. 포스트잇 표시 시간을 1초와 20초로 바꿔 확인합니다.
2. **이력·절전 복귀**: 실제 알림을 닫고/다시 알림으로 보내 각각 확인·예약 상태를 확인합니다. 알림 시각을 사이에 두고 절전 후 복귀하여 최근 누락 건이 알림별 하나로 복구되는지 확인합니다. 간격 알림이 여러 번 몰려 나오지 않는지 확인합니다.
3. **방해 금지**: 직접 해제 모드를 켜고 알림 시각을 지나갑니다. 그림·말풍선·소리가 나오지 않고 해제 후 알림이 표시되는지 확인합니다. 전체 화면 자동 숨김도 확인합니다. 측정 중인 타이머·스톱워치가 계속 진행되는지 확인합니다.
4. **백업·복원**: 설정을 백업한 뒤 바꾸고 복원·재시작하여 원래 설정으로 돌아오는지 확인합니다. 잘못된 백업·값 범위 밖 데이터는 거절되고 이전 설정이 보존되는지 확인합니다. 복원 전 자동 백업 폴더도 확인합니다.
5. **완료 취소**: 메모 완료 모션 뒤 되돌리기를 누르면 진행 중으로 복구되는지 확인합니다. 완료 날짜와 재실행 후 유지, 완료 목록에서 복원을 확인합니다.
6. **통합 설정**: 5개 탭을 반복 이동하고 메시지 편집·미리보기 대화상자를 열어봅니다. 잘못된 값으로 창을 닫으면 닫힘을 막는지 확인합니다. 프로그램 탭에서 백업 시 설정 창이 저장 후 닫히는지 확인합니다.
7. **활동 시간**: 1분 간격, 가까운 시작·종료 시각으로 설정합니다. 범위 밖에서 울리지 않고 복귀 후 간격이 새로 계산되는지 확인합니다. 22:00~06:00, 평일/주말, 입력 5분 자리 비움, 수면 기능 OFF 상태에서도 중단되는지 확인합니다.
8. **화면 배치**: 주/보조 모니터 100%·125%·150% 혼합 배율, 보조 화면 음수 좌표, 주 모니터 변경, 1920×1080→1366×768 전환을 확인합니다. 포스트잇·측정 창을 보조 모니터에 두고 분리했을 때 접근 가능한 영역으로 돌아오는지 확인합니다. 고정 메모의 복구 위치를 재실행 후에도 확인합니다. 캐릭터 낙하 도중 모니터 분리, 최대 크기 500, 긴 알림 메시지도 확인합니다.

## 자동 테스트 실행 (Developer Command Prompt)

```bat
msbuild tests\ScheduleTests.csproj /t:Rebuild
 tests\bin\ScheduleTests.exe
```

기대 결과: `PASS: 21 scheduling assertions`

## 앉은 자세 마우스 회피

- 마우스 피하기 ON + ‘모두 잠깐 쉬기’ 상태에서 커서를 양쪽으로 접근시키면 앉은 채 반대 방향으로 천천히 이동하는지 확인합니다.
- 머리·팔·엉덩이 높이는 유지되고 양쪽 발만 작게 움직이는지 확인합니다. 크기 50·80·180·500에서도 확인합니다.
- 커서를 멀리 옮기거나 옵션을 OFF로 바꾸면 원래 앉은 자세로 정지하고 쉬기 상태가 유지되는지 확인합니다.
- 자동으로 앉아 쉬는 상태에서도 동일한 동작이 나오는지, 이미 걷고 있던 캐릭터는 기존 빠른 걷기 회피를 유지하는지 확인합니다.
- 화면 가장자리에서 벗어나지 않는지, 회피 도중 클릭·드래그·알림이 들어오면 해당 동작으로 정상 전환하는지 확인합니다.
# 멀티모니터 알림 회귀 확인 (1.40.5)

- 모니터 3대에 일반 춘식이를 한 마리씩 배치하고 문구 3개인 알림을 실행한다. 각 춘식이 위에 서로 다른 문구 하나씩 모두 표시되는지 확인한다.
- 가운데 모니터를 주 모니터로 설정해 왼쪽 화면의 X 좌표가 음수가 되게 한다. 위·아래로 어긋난 배치도 확인한다.
- 화면 배율을 100% / 150% / 200%로 설정하고 세 춘식이를 다른 모니터로 왕복 드래그한다. DPI 경계에서도 드래그가 풀리거나 다른 춘식이가 이동하지 않아야 한다.
- 알림 표시 전과 표시 중 각각 드래그한다. 말풍선이 해당 춘식이의 모니터를 따라가며 화면 밖으로 사라지지 않는지 확인한다.
- 한 모니터에 세 마리를 모아 문구가 겹치지 않는지, 다시 분산하면 각 모니터로 돌아가는지 확인한다.
- 문구 5개 / 춘식이 3마리에서는 3개 표시 후 나머지 2개가 자동 표시되는지 확인한다. 같은 시각 알림 3개(각 문구 1개)도 확인한다.
- 각 화면에서 다시 알림·닫기 버튼을 눌러 동작을 확인한다. 방해 금지를 껐을 때 알림이 복귀하는지도 확인한다.

자동 테스트는 픽셀 좌표 배치 계산을 검증한다. 실제 Windows의 HWND/DPI 이벤트, 드래그와 화면 출력은 위 수동 확인이 필요하다.

## 예약 알림·카운트다운 (1.41.0)

- 모든 알림을 닫은 뒤 1분 후 알림을 설정하고, 남은 시간이 매초 줄어 0초에 세 문구가 표시되는지 확인한다.
- 같은 알림을 오늘 이미 울린 후 다시 1분 뒤로 수정한다. 새 시각에 다시 울리며 문구만 수정할 때는 중복 발송되지 않아야 한다.
- 앞선 알림의 마지막 말풍선을 닫지 않은 채 다음 예약을 기다린다. 표시 시간이 지나면 다음 알림으로 자동 전환되어야 한다.
- 같은 간격 알림의 말풍선을 계속 열어둬도 다음 회차가 대기 후 표시되는지 확인한다.
- 요일 미선택·알림 끄기·활동 시간 밖·자리 비움·방해 금지 상태를 설정하고 행의 안내가 실제 상태와 일치하는지 확인한다.
- 특정 날짜의 시간 지정/미지정, 다시 알림, 설정 창 닫았다 열기에서 남은 시간과 예정 시각을 확인한다.
# 포스트잇 직접 조작 (1.42.0)

- 메모 앞에 네모가 자동으로 붙지 않는지 확인한다. A−/A+를 눌러 두 포스트잇의 글자 크기가 독립적으로 변경되는지 확인한다.
- ＋로 빈 메모를 추가하고 바로 한국어·여러 줄 내용을 입력한다. 빈 상태로도 재시작 후 남아야 한다.
- 오른쪽 아래 ◢를 끌어 가로·세로를 조절한다. 다른 메모의 크기에 영향이 없어야 하고 내용이 길면 스크롤돼야 한다.
- 내용 더블클릭 → Enter 줄바꿈 → Ctrl+Enter 저장, 다시 편집 → Esc 취소, 외부 클릭 저장을 확인한다.
- 가끔 표시 모드에서 편집하는 동안 표시 시간이 지나도 숨지 않아야 한다. 완료 애니메이션·되돌리기도 확인한다.
- 프로그램 재시작 및 설정 백업·복원 후 빈 메모, 내용, 글자 크기, 창 크기가 유지되는지 확인한다. 예전 백업도 기본 크기로 복원돼야 한다.
# 첨부 개선표 회귀 확인 (1.42.2~1.45.0)

- 트레이와 춘식이 우클릭으로 크기·속도를 변경하고 종료/재실행/한 마리 추가 후 값이 유지되는지 확인한다. 모두에게 적용한다는 메뉴 표기도 확인한다.
- 3초 타이머를 실행한다. 완료 말풍선·이력·전담 모션, 5초 간격 소리, 완료 확인 후 중단을 확인한다. 방해 금지 중 완료 후 해제 시 표시하고 다시 알림 중에는 반복 소리가 없어야 한다.
- 1366×768, 125%·150% 배율에서 알림 탭의 가로 스크롤이 없고 목록·상세 카드가 세로로 접히는지 확인한다. 추가·삭제·종류·요일·시간·메시지 편집과 카운트다운을 확인한다.
- 캐릭터 슬라이더/스위치를 바꿔 즉시 반영되는지, 저장 버튼 없이 닫았다 열어도 유지되는지 확인한다. 입력 중인 잘못된 수면 시간은 오류 표시하고 창 닫기를 막아야 한다.
- 5분 뒤 다시 알림 → 2분 후 재실행 → 약 3분 후 표시를 확인한다. 예정 시각이 지난 후 재실행하면 대기로 복구돼야 한다.
- 30분 방해 금지와 직접 해제 모드를 각각 설정 후 재실행한다. 남은 종료 시각/직접 해제 모드가 유지되며 대기 알림도 해제 뒤 표시돼야 한다.
